Responde con tus propias palabras.

1. ¿Qué significa repetir instrucciones en programación?

Respuesta: permite hacer que se automicen procesos y hacerlos varias veces sin tener que volver a escribir el bloque de codigo.

2. ¿Qué es un ciclo while?

Respuesta: es un comando de condición repetitiva que realiza un codigo de informacion y arroja ya sea verdadero o falso si es con variables alfabeticas.

3. ¿Qué significa la condición dentro de un while?

Respuesta: es un mientra que se utiliza para encontrar una información o se cumpla la cantidad de ciclos que se defina como los númericos.

4. ¿Por qué es importante cambiar una variable dentro del while?

Respuesta: porque estas a ser cambiantes hay que definir un lugar para que estas no se conviertan en un ciclo infinito.

5. ¿Qué es un ciclo infinito?

Respuesta: es un bucle que no se le ha definido un ítem de salida y siempre va a tener resultado y sin ninguna terminación.

6. ¿Qué hace el comando npm run practicar?

Respuesta: es el responsable de hacer que se automaticen los comandos en una hoja de desarrollo con las líneas de codigos que se estan utilizando.

7. ¿Dónde está definido el comando practicar?

Respuesta: package.json en scripts.

8. ¿Qué diferencia hay entre node archivo.js y npm run practicar?

Respuesta: el node archivo.js ejecuta directamente el archivo de JS mientras que el npm run corre un archivo con el riesgo de que se deriven comandos mas complejos.

9. ¿Cómo puede servir un while para revisar varias fuentes de información?

Respuesta: sirve para repetir instrucciones en diferentes fuentes de información y buscar los datos que le son asignados hasta agotar todos los archivos que se le dieron a analizar.

10. ¿Cómo puede relacionarse un ciclo con el seguimiento de propuestas comunitarias?

Respuesta: se puede utilizar la analogia porque cuando hay un ciclo constante en revisar propuestas e ir implementarto cada vez que se pueda para estar mejorando y volverlo constante y un bucle para que se presente un bienestar de la población.
